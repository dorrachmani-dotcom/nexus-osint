⬆ Export a bundle

Run this on the collecting machine, then save the file to your USB stick.

⬇ Import a bundle

Run this on the offline machine. New items, analyses, scores and evidence are merged in. Importing the same bundle twice is safe — duplicates are skipped automatically.

Bundles never contain API keys or settings — only collected items, their analysis, question scores and captured evidence. They are ordinary ZIP files with a .nexusbundle name.

How the two-machine workflow works (full guide)

The idea is to keep your sensitive analysis machine completely offline (air-gapped) while still feeding it fresh intelligence. One machine does the collecting; the other does the analysis. A USB stick carries the data across the gap.

Machine A — the online collector

Connected to the internet. Gathers and organizes everything.

  1. Add your sources and run a Scan so new items are collected and analyzed as usual.
  2. Open this Transfer page.
  3. Under Export a bundle, choose Everything or a single Case.
  4. For a daily routine, tick “Only new items since the last export.” This carries just the new items collected since last time, so the file stays small and fast.
  5. Click Download bundle and copy the .nexusbundle file to a USB stick.

Machine B — the offline analysis station

Never connected to any network. Runs the same app.

  1. Plug in the USB stick and open this Transfer page.
  2. Under Import a bundle, pick the .nexusbundle file and click Import bundle.
  3. Every new item is merged in — with its summary, translation, entities, question scores and evidence screenshots — and a short summary of what was added is shown.
  4. The new items now appear in the feed and search like anything else.

A daily routine (example)

Say you track one subject every day. Each morning on Machine A: Scan → Transfer → tick Only new items since the last export → Download → carry the small bundle to Machine B → Import. Machine B steadily builds the full picture while never touching the internet.

Good to know

  • Safe to repeat: importing the same bundle twice adds nothing new — duplicates are detected by content and skipped.
  • No secrets travel: bundles contain only collected data and its analysis — never API keys or settings.
  • Links stay, but stay offline: article links are preserved for reference; on an offline machine they simply won't open, which is expected.
  • Both directions work: you can also export from B and import into A if you ever need to move data the other way.
