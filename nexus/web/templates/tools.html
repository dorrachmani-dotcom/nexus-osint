🔧 How to install these tools (and what each one is for)

Easiest way — Docker (everything included)

If you run Nexus with Docker, all of these tools are already installed inside it — there's nothing to do. Install the tools below only if you run Nexus directly on your computer.

One-time setup for the manual route

  1. Install Python from python.org (tick "Add to PATH").
  2. Open a terminal and run once: python -m pip install --user pipx then python -m pipx ensurepath.
  3. Close and reopen the terminal. Now you can install any Python tool below with one line.
  4. After installing a tool, reopen Nexus — it detects it automatically.
