Choosing the AI (or none)

⭐ Local AI model (Ollama) — no key, 100% offline, free

What it is: instead of sending your text to a cloud service like ChatGPT or Gemini, Ollama runs the AI directly on this computer. The AI "brain" is a file that lives on your own machine, so nothing you analyse ever leaves it. This is the most private option, and there is no account, no API key, and no cost.

Set up once (about 5 minutes):

  1. Download the free Ollama app from ollama.com/download and install it like any normal program. Once installed it keeps running quietly in the background — you don't need to open it again.
  2. Back here, choose "Local model (Ollama)" in the AI provider box on the left and click Save.
  3. Click Download model and pick one from the list. Each option shows its size and the memory (RAM) it needs. This is a one-time download of a few gigabytes, so it can take several minutes — no terminal or commands required.
  4. Click Test connection. When it turns green, the local AI is working and will summarise, translate and threat-score your items.

Good to know: a local model uses your computer's own power, so it's slower than the cloud options and works best on a reasonably modern machine with enough RAM (the list tells you what each model needs). The trade-off is total privacy — your data never goes online. Not sure which to pick? Start with the smallest one the list allows for your computer.

No AI at all ("Off")

Items are still collected, stored and fully searchable — just not summarised, translated or threat-scored. You can switch an AI on later.

RSS (no key)

Add feed URLs to RSS_FEEDS (comma-separated). This is the always-on backbone.

Claude analysis (Anthropic)

Get a key at console.anthropic.com → set ANTHROPIC_API_KEY. Without it, items are stored without analysis.

Gemini analysis (Google)

Get a key at aistudio.google.com → set GEMINI_API_KEY, then pick "Google (Gemini)" as the provider above.

ChatGPT analysis (OpenAI)

Get a key at platform.openai.com → set OPENAI_API_KEY, then pick "OpenAI (ChatGPT)" as the provider above.

Grok analysis (xAI)

Get a key at console.x.ai → set XAI_API_KEY, then pick "xAI (Grok)" (or "Automatic") as the provider.

Local server (LM Studio, llama.cpp, vLLM, Jan, LocalAI)

Already run AI models in one of these apps? Start its OpenAI-compatible server, pick "Local server" as the provider, then Test connection and save a model. Like Ollama, nothing leaves this computer.

Automatic (default)

Uses the first AI that is ready: Gemini, OpenAI, Anthropic, Grok, then a local server with a model picked. Choose a provider explicitly to pin it.

SERPAPI (news)

Register at serpapi.com → set SERPAPI_KEY and one or more SERPAPI_QUERIES.

Reddit

Create an app at reddit.com/prefs/apps → set REDDIT_CLIENT_ID, REDDIT_CLIENT_SECRET, and REDDIT_SUBREDDITS.

Twitter / X

Get a bearer token from the X developer portal → set TWITTER_BEARER_TOKEN and TWITTER_QUERIES.

Telegram (Telemetry)

Telegram coverage uses telemetryapp.io (the Telemetry search/analytics API). Generate an access key from its @telemetrio_api_bot on Telegram → set TELEMETRY_API_KEY. Then list public channels in TELEGRAM_CHANNELS (e.g. durov, telegram). Your investigation queries are also searched across all public Telegram automatically.

OSINT CLI tools

Sherlock, Maigret, theHarvester and SpiderFoot are auto-detected on PATH (bundled in the Docker image). Missing tools are skipped.
